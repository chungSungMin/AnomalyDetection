




## CoreSet 구하기
일반적으로 d=1536처럼 매우 높은 차원을 가지고 있습니다. 하지만 coreset을 구하기 위해서 모든 d차원의 벡터들과의 계산을 진행해야합니다. 이렇게 되면 매우 많은 연산량이 들어가게됩니다.
그래서 해당 논문에서는 수학적으로 매우 영리하게 해당 문제를 해결합니다.

그 방법은 바로 랜덤 선형 투영을 통해서 차원을 더 작은 차원으로 낮추는것 입니다. 
특정 고차원의 벡터에 고차원의 선형행렬을 투과하면 성질이 유지되고, 결국 벡터들간의 거리 비율은 유지되는 효과를 얻을 수 있습니다.

우리가 3차원 혹은 2차원에서 랜덤하게 2개의 선을 그리면 두 선이 직각이 될 확률은 매우 적습니다. 하지만 1536차원이라면 이야기가 달라집니다. 실제로 매우 높은 차원에서 랜덤으로 벡터를 구하고 내적을 
해보면 거의 0에 가까운 값이 나온다고합니다. 이는 결국 1536차원의 행렬을 구하게 되면 해당 행렬은 직교행렬이 되고, 결국 직교행렬을 투영하게 되면 대칭이동 혹은 회전만 일어나기 때문에 기존의 벡터의 성질은
유지되게 된다고 합니다. 

그래서 결국 coreset을 구하는 과정에서 해당 논문에서는 1536차원을 모두 계산하는게 아니라 전에 더 작은 차원으로 투영을 시킨 후 빠르게 벡터들간의 거리를 구해서 인덱스를 구한후 해당 인덱스를 기반으로 원본 d차원의 벡터를 메모리 뱅크에 저장하는 방법을 사용한다고 합니다.

이러한 방법을 통해서 연산량을 줄이면서 coreset을 구할 수 있게 됩니다.
